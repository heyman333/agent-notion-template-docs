이미지 업로드 지연 장애 분석

장애 보고 2026-02-10 · 작성: 홍길동

현상

2월 9일 14:00–16:30, 이미지 업로드 API 의 p95 응답이 평소 0.8초에서 14초까지 치솟았다. 타임아웃 오류율 6.2%. 트래픽 증가는 없었고, 같은 시간대에 배포된 v2.31.0 이후 시작됐다.

🚨
영향 — 2시간 30분 동안 업로드 시도의 6.2%(약 4,100건)가 실패. 롤백으로 즉시 정상화됨.

원인

v2.31.0 에서 추가된 썸네일 생성이 요청 스레드를 막고 있었다.

# v2.31.0 — 문제 코드: 업로드 응답 전에 썸네일 3종을 동기로 생성
def upload_image(file):
    key = storage.put(file)
    for size in (1200, 600, 200):        # 요청당 최대 9초 소요
        thumb = resize(file, size)
        storage.put_thumb(key, size, thumb)
    return {"key": key}
⚠️
스테이징에서는 작은 테스트 이미지만 써서 재현되지 않았다 — 원본 크기 분포가 실사용과 달랐던 것이 탐지 실패의 원인.

수정안

썸네일 생성을 응답 경로에서 떼어내 큐로 보낸다.

# v2.31.1 — 수정: 썸네일은 비동기 워커가 처리
def upload_image(file):
    key = storage.put(file)
    thumbnail_queue.enqueue(key)          # 응답은 원본 저장까지만
    return {"key": key, "thumbnails": "processing"}
요청 경로에는 사용자가 기다려야 하는 일만 남긴다.
